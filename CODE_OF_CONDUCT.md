# Code of conduct

This project welcomes learners from different technical backgrounds. Critique decisions and evidence respectfully. Explain unfamiliar terms, acknowledge uncertainty, and let contributors correct mistakes.

Harassment, discriminatory remarks, threats, sexualized conduct, disclosure of private information, and repeated personal attacks are unacceptable in project issues, pull requests, discussions, or other project-managed spaces.

## Reporting and response

For a non-sensitive conduct concern, contact a repository maintainer through a public issue requesting a private contact route without naming affected people or including incident details. For sensitive reports, use a private contact method the maintainer has explicitly published on their GitHub profile. This repository does not currently advertise a dedicated confidential conduct inbox. Do not post private evidence publicly to compensate for that limitation.

Maintainers should acknowledge reports when able, limit sharing to people needed to investigate, and explain any action to the affected participants when safe. Depending on severity, they may request edits, remove content, warn, temporarily restrict participation, or ban a participant. A person involved in a report should not adjudicate it alone; request an uninvolved maintainer where available.

Example: "This retry design can duplicate writes; please show an idempotency test" is useful criticism. Attacking a contributor's competence or identity is not. If you disagree with moderation, request review with new facts through the same reporting route. No response-time guarantee is offered.
